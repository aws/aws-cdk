# CDK skill authoring

A skill for writing and editing the review skills in [`skills/cdk-review/`](../cdk-review/README.md).

| Skill | Use |
|---|---|
| [`cdk-review-skill-authoring`](./cdk-review-skill-authoring/SKILL.md) | Writing and editing the review skills in [`skills/cdk-review/`](../cdk-review/README.md) |

## Install

```sh
npx skills add https://github.com/aws/aws-cdk/tree/main/skills/cdk-skill-authoring --skill '*' -g
```

From an aws-cdk checkout:

```sh
npx skills add ./skills/cdk-skill-authoring --skill '*' -g
```
