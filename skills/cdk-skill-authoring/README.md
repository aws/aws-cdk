# CDK skill authoring

Skills for writing and editing the skills in this repository.

| Skill | Use |
|---|---|
| [`cdk-review-skill-authoring`](./cdk-review-skill-authoring/SKILL.md) | Writing and editing the review skills in [`skills/cdk-review/`](../cdk-review/README.md) |

## Install

```sh
npx skills add aws/aws-cdk --skill cdk-review-skill-authoring -g
```

From an aws-cdk checkout:

```sh
npx skills add ./skills/cdk-skill-authoring --skill '*' -g
```
